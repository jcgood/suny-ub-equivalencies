# SUNY to UB Course Equivalencies

An unofficial, linkable copy of the University at Buffalo's TAURUS Course
Equivalency Guide (https://www.buffalo.edu/taurus.html), limited to SUNY
campuses. It repackages TAURUS's public data so that a view can be shared by
URL:

- `?school=<TAURUS school id>` (optionally `&course=BIOL115`): rules for one SUNY campus
- `?ub=BIO200` (optionally `&school=<id>`): rules leading to one UB course

TAURUS is the official record. This copy shows the retrieval date on every
page and links each view to the matching live TAURUS data. Not affiliated
with or endorsed by the University at Buffalo.
